The interface, the Markov property and dynamics

What an agent sees, what the environment does, and how one function describes the whole environment.

0Introduction: the agent–environment interface

Reinforcement Learning (RL) formalizes the problem of learning from interaction to achieve a goal. The decision-maker is called the agent, and everything outside the agent is the environment.

The interaction unfolds continuously across discrete time steps \(t \in \{0, 1, 2, 3, \ldots\}\):

  • At time step \(t\), the agent receives a representation of the environment's state: \(S_t \in \mathcal{S}\).
  • Based on this state, the agent selects an action: \(A_t \in \mathcal{A}(s)\).
  • One time step later, as a consequence of its action, the agent receives a numerical reward: \(R_{t+1} \in \mathcal{R} \subset \mathbb{R}\).
  • The environment transitions into a new state: \(S_{t+1} \in \mathcal{S}\).

This interaction generates a sequential trajectory of random variables:

$$S_0 \longrightarrow A_0 \longrightarrow (S_1, R_1) \longrightarrow A_1 \longrightarrow (S_2, R_2) \longrightarrow A_2 \longrightarrow (S_3, R_3) \longrightarrow \ldots$$

1The Markov property & transition dynamics

General history-dependent distribution

In an arbitrary stochastic process, the joint probability of reaching state \(s'\) with reward \(r\) at time \(t+1\) depends on the entire historical sequence of past states, actions, and rewards:

$$P(S_{t+1}=s', R_{t+1}=r \mid S_t=s_t, A_t=a_t, R_t=r_t, S_{t-1}=s_{t-1}, A_{t-1}=a_{t-1}, \ldots, S_0=s_0, A_0=a_0)$$

The Markov property definition

A state \(S_t\) satisfies the Markov property if and only if the conditional probability distribution of future states and rewards depends only upon the present state and action, rendered conditionally independent of all past history.

$$\begin{aligned}&P(S_{t+1}=s', R_{t+1}=r \mid S_t=s_t, A_t=a_t, S_{t-1}=s_{t-1}, \ldots, S_0=s_0)\\ &= P(S_{t+1}=s', R_{t+1}=r \mid S_t=s_t, A_t=a_t)\end{aligned}$$

If a state possesses the Markov property, it retains all relevant information from the past to predict the future.

Drone check supplementIf the drone is in Low and delivers, the chance of ending in Critical is \(0.7\) — whether it got to Low by delivering from High a moment ago or after a long recharge. The battery level alone is enough to predict what happens next; that is exactly what makes "battery level" a Markov state. If, say, an ageing battery drained faster after many flights, the battery level alone would no longer be Markov, and we would add the flight count to the state.

Four-argument joint transition dynamics

For a Markov Decision Process (MDP) with finite state and reward spaces, the environment's response is fully defined by a four-argument transition function \(p : \mathcal{S}\times\mathcal{R}\times\mathcal{S}\times\mathcal{A} \to [0,1]\):

$$p(s', r \mid s, a) \doteq P(S_{t+1}=s', R_{t+1}=r \mid S_t=s, A_t=a)$$
\(\doteq\) means "is defined as". \(s, a\): where you are and what you do now; \(s', r\): what the environment returns.

Probability axiom

Because \(p(s', r \mid s, a)\) is a valid conditional probability distribution for every state–action pair \((s,a)\), the sum of probabilities over all possible next states \(s'\) and rewards \(r\) must equal 1:

$$\sum_{s' \in \mathcal{S}} \sum_{r \in \mathcal{R}} p(s', r \mid s, a) = 1 \quad \forall\, s \in \mathcal{S},\ a \in \mathcal{A}(s)$$
Drone check supplementTake \((s,a) = (\text{Low}, \text{Deliver})\). Delivering from Low always pays \(r = +6\), so \(p\) puts mass only on \(r=6\): \(p(\text{Low}, 6 \mid \text{Low}, \text{Del}) = 0.3\) and \(p(\text{Crit}, 6 \mid \text{Low}, \text{Del}) = 0.7\). Every other \((s', r)\) pair has probability 0. Sum: \(0.3 + 0.7 = 1\) ✓. In an environment with random rewards (a tip, say) the same 1.0 would be spread over several values of \(r\).

B1Background: marginal probability (the sum rule) supplement

Why it is needed. Byte 2 sums \(p(s', r \mid s,a)\) over \(r\). That step is the sum rule of probability.

$$P(X = x) = \sum_{y} P(X = x, Y = y)$$
To get the probability of \(X\) alone (its marginal), add the joint probability over every value \(Y\) can take. The name comes from old tables, where these row sums were written in the margin.

Example. A joint table over (weather, bus late): P(rain, late) = 0.20, P(rain, on time) = 0.10, P(dry, late) = 0.15, P(dry, on time) = 0.55. Then P(rain) = 0.20 + 0.10 = 0.30. Sanity check: P(rain) + P(dry) = 0.30 + 0.70 = 1.

The same rule holds inside a condition: \(P(X=x \mid C) = \sum_y P(X=x, Y=y \mid C)\).

2Marginalization of dynamics

From the complete four-argument joint transition distribution \(p(s', r \mid s, a)\), we can compute intermediate quantities by marginalizing over unneeded random variables.

State transition probability

The two-argument state transition probability \(P(s' \mid s, a)\) defines the likelihood of transitioning to state \(s'\) given current state \(s\) and action \(a\), regardless of the immediate reward received:

$$P(s' \mid s, a) \doteq P(S_{t+1}=s' \mid S_t=s, A_t=a) = \sum_{r \in \mathcal{R}} p(s', r \mid s, a)$$

Why marginalize over \(r\)? Marginalizing over rewards isolates spatial and structural routing dynamics from scalar reward noise or feedback variance. It allows us to analyze how an agent moves through state space independently of the specific payoff structure.

Expected immediate reward

The expected immediate reward function \(R(s,a)\) computes the expected value of the reward \(R_{t+1}\) given state \(s\) and action \(a\):

$$R(s,a) \doteq \mathbb{E}[R_{t+1} \mid S_t=s, A_t=a] = \sum_{r \in \mathcal{R}} r \cdot P(R_{t+1}=r \mid S_t=s, A_t=a) = \sum_{s' \in \mathcal{S}} \sum_{r \in \mathcal{R}} r \cdot p(s', r \mid s, a)$$
An expected value is a probability-weighted average of the possible values (made precise in Byte B2).
Drone check supplementFrom Byte 1, \((\text{Low}, \text{Deliver})\) has mass 0.3 on \((\text{Low}, 6)\) and 0.7 on \((\text{Crit}, 6)\).
\(P(\text{Crit} \mid \text{Low}, \text{Del}) = \sum_r p(\text{Crit}, r \mid \text{Low}, \text{Del}) = 0.7\), and the row \(P(\cdot \mid \text{Low}, \text{Del}) = [0.0, 0.3, 0.7]\) is the row shown in the example table.
\(R(\text{Low}, \text{Del}) = 6\cdot 0.3 + 6 \cdot 0.7 = 6\). Because this drone's reward is fixed for each \((s,a)\), \(R(s,a)\) is just the table value. These two marginals, \(P\) and \(R\), are all the dynamic-programming algorithms of Lecture 2 need.
Shape checkFor each fixed action \(a\), \(P(\cdot \mid \cdot, a)\) is an \(N \times N\) table whose rows sum to 1; \(R(\cdot, \cdot)\) is an \(N \times |\mathcal{A}|\) table in reward units.

What the agent does, and what it wants

The policy describes behavior; the return measures success; value functions predict the return.

3The agent's policy (\(\pi\))

A policy \(\pi\) defines the agent's behavior at any given state.

Formal definition

A stochastic policy \(\pi(a \mid s)\) specifies the probability distribution over actions \(a \in \mathcal{A}(s)\) given state \(s\):

$$\pi(a \mid s) \doteq P(A_t = a \mid S_t = s)$$

Probability axioms

For all states \(s \in \mathcal{S}\):

$$\sum_{a \in \mathcal{A}(s)} \pi(a \mid s) = 1 \qquad\qquad \pi(a \mid s) \ge 0 \quad \forall\, a \in \mathcal{A}(s)$$

Policy variants

  • Stochastic policy: \(\pi(a \mid s) \in [0,1]\). The agent samples actions probabilistically, enabling exploration and optimal play in partially observable or competitive settings.
  • Deterministic policy: \(\pi(s) = a\). The agent deterministically maps state \(s\) to a single action \(a\), placing all probability mass on one action: $$\pi(a \mid s) = \begin{cases} 1 & \text{if } a = \pi(s) \\ 0 & \text{if } a \ne \pi(s) \end{cases}$$
Drone check supplementThe deterministic policy \(\pi_1 = (\text{Deliver}, \text{Deliver}, \text{Recharge})\) (one action per state, in the order High, Low, Critical) has \(\pi_1(\text{Del} \mid \text{High}) = 1,\ \pi_1(\text{Rech} \mid \text{High}) = 0\), and so on. A stochastic alternative, \(\pi_{\text{mix}}\), is the same except that in Low it flips a fair coin: \(\pi_{\text{mix}}(\text{Del} \mid \text{Low}) = \pi_{\text{mix}}(\text{Rech} \mid \text{Low}) = 0.5\). Each row sums to 1 ✓. We reuse \(\pi_{\text{mix}}\) in Bytes B2 and 7.

4The discounted cumulative return (\(G_t\))

The goal of the agent is to maximize long-term cumulative reward, formally known as the return.

Definition

The discounted cumulative return \(G_t\) from time step \(t\) onward is defined as:

$$G_t \doteq R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \ldots = \sum_{k=0}^{\infty} \gamma^{k} R_{t+k+1}$$
where \(\gamma \in [0,1)\) is the discount factor: a reward \(k\) steps away counts \(\gamma^k\) as much as one received now.
Note on \(\gamma = 1\) supplementFor episodic tasks (which always end, e.g. a game), \(\gamma = 1\) is also allowed, because the sum then has finitely many terms. Requiring \(\gamma < 1\) is what we need for continuing tasks, and it is what Lecture 2's convergence proofs use.

Role of the discount factor (\(\gamma\))

  • Mathematical convergence: ensures that \(G_t\) remains finite for continuing tasks with infinite horizons, provided rewards are bounded: \(|R_t| \le R_{\max} \implies |G_t| \le \dfrac{R_{\max}}{1-\gamma}\). corrected (the bound is on \(|G_t|\); it follows from the geometric series \(1 + \gamma + \gamma^2 + \ldots = 1/(1-\gamma)\).)
  • Temporal preference & uncertainty: reflects preference for immediate rewards over deferred rewards, modeling interest rates, risk, or environment non-stationarity.

Fundamental recursive identity

The return \(G_t\) can be split recursively into immediate reward plus the discounted return of the next time step:

$$\begin{aligned}G_t &= R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \gamma^3 R_{t+4} + \ldots\\ &= R_{t+1} + \gamma\left(R_{t+2} + \gamma R_{t+3} + \gamma^2 R_{t+4} + \ldots\right)\\ &= R_{t+1} + \gamma G_{t+1}\end{aligned}$$

This recursive property is the structural foundation for all dynamic programming and temporal-difference algorithms.

Drone check supplementOne possible episode fragment: High →(Deliver, \(+10\))→ Low →(Recharge, \(-1\))→ High →(Deliver, \(+10\)), and suppose the story stops there. With \(\gamma = 0.8\):
Directly: \(G_0 = 10 + 0.8(-1) + 0.8^2(10) = 10 - 0.8 + 6.4 = 15.60\).
Backwards with the recursion: \(G_2 = 10\); \(G_1 = -1 + 0.8 \cdot 10 = 7.00\); \(G_0 = 10 + 0.8 \cdot 7 = 15.60\) ✓ — same number, computed from the end.
Bound: the largest reward is \(R_{\max} = 10\), so no return in this MDP can exceed \(10 / (1 - 0.8) = 50\) in absolute value.
Units check\(\gamma\) is unitless, so \(G_t\) has the same units as the rewards.

B2Background: expectation, conditioning and the law of total expectation supplement

Why it is needed. \(G_t\) is random (actions and transitions are random), so we cannot ask for "the" return of a state, only its average. Byte 5 defines values as expectations, and Byte 6 manipulates them with three rules collected here.

$$\mathbb{E}[X] = \sum_{x} x\, P(X = x) \qquad \mathbb{E}[X \mid C] = \sum_{x} x\, P(X = x \mid C)$$
The expectation is a probability-weighted average of the values \(X\) can take; conditioning on \(C\) just uses the conditional probabilities. \(\mathbb{E}_{\pi}\) means "actions are drawn from \(\pi\)".
  1. Linearity: \(\mathbb{E}[X + cY \mid C] = \mathbb{E}[X \mid C] + c\, \mathbb{E}[Y \mid C]\) for a constant \(c\).
  2. Constants come out: if \(C\) fixes \(X = x\), then \(\mathbb{E}[X \mid C] = x\).
  3. Law of total expectation: to average over \(X\), first split by the value of some other variable \(Y\), average within each case, then weight the cases: $$\mathbb{E}[X \mid C] = \sum_{y} P(Y = y \mid C)\ \mathbb{E}[X \mid C, Y = y]$$

Example (drone). Under \(\pi_{\text{mix}}\) in state Low, what reward do we expect on the next step? Split by the action (rule 3): \(\mathbb{E}_{\pi_{\text{mix}}}[R_{t+1} \mid S_t = \text{Low}] = 0.5 \cdot R(\text{Low}, \text{Del}) + 0.5 \cdot R(\text{Low}, \text{Rech}) = 0.5(6) + 0.5(-1) = 2.50\). Sanity check: the answer lies between the two possible rewards, \(-1\) and \(6\), as any average must.

5The value functions (\(V^{\pi}\) and \(Q^{\pi}\))

Value functions estimate how good it is for an agent to be in a given state (or perform a given action in a given state) under a specific policy \(\pi\).

State-value function (\(V^{\pi}\))

The state-value function \(V^{\pi}(s)\) is the expected return starting from state \(s\) at time step \(t\) and following policy \(\pi\) thereafter:

$$V^{\pi}(s) \doteq \mathbb{E}_{\pi}[G_t \mid S_t = s]$$

Action-value function (\(Q^{\pi}\))

The action-value function \(Q^{\pi}(s,a)\) is the expected return starting from state \(s\), taking action \(a\), and thereafter following policy \(\pi\):

$$Q^{\pi}(s,a) \doteq \mathbb{E}_{\pi}[G_t \mid S_t = s, A_t = a]$$
Reading the numbers supplementFor the drone policy \(\pi^{*} = (\text{Deliver}, \text{Recharge}, \text{Recharge})\) we will find (Byte 8) \(V^{\pi^*} = \left[30.0000,\ 21.6667,\ 18.6667\right]^{T}\). Read \(V^{\pi^*}(\text{High}) = 30\) as: "start fully charged, follow \(\pi^*\) forever, and the discounted rewards add up to 30 on average." Some runs earn more, some less; 30 is the mean. It stays below the bound of 50 from Byte 4, as it must.
Shape check\(V^{\pi}\) is one number per state (\(N\) numbers); \(Q^{\pi}\) is one number per state–action pair (an \(N \times |\mathcal{A}|\) table). Both are in reward units.

The Bellman equations

Values satisfy self-consistency equations: first for a fixed policy (linear), then for the best policy (non-linear).

6Step-by-step derivation of the Bellman expectation equation for \(V^{\pi}(s)\)

Here is the analytical derivation decomposing \(V^{\pi}(s)\) into immediate expected rewards and discounted downstream values. Each step uses one rule from Byte B2 or the Markov property (Byte 1).

Step A: substitute the recursive return

Start with the definition of the state-value function and expand \(G_t\) using its recursive identity (Byte 4):

$$V^{\pi}(s) = \mathbb{E}_{\pi}[G_t \mid S_t = s] = \mathbb{E}_{\pi}[R_{t+1} + \gamma G_{t+1} \mid S_t = s]$$

Step B: condition on action selection (law of total expectation)

To evaluate the expectation, expand over all candidate actions \(a \in \mathcal{A}(s)\) chosen by policy \(\pi(a \mid s)\):

$$\begin{aligned}V^{\pi}(s) &= \sum_{a \in \mathcal{A}(s)} P(A_t = a \mid S_t = s) \cdot \mathbb{E}_{\pi}[R_{t+1} + \gamma G_{t+1} \mid S_t = s, A_t = a]\\ &= \sum_{a \in \mathcal{A}(s)} \pi(a \mid s) \cdot \mathbb{E}_{\pi}[R_{t+1} + \gamma G_{t+1} \mid S_t = s, A_t = a]\end{aligned}$$

Step C: condition on environment response (law of total expectation)

Condition the inner expectation over all possible outcomes realized by the environment — specifically next state \(s'\) and reward \(r\) — weighted by \(p(s', r \mid s, a)\):

$$V^{\pi}(s) = \sum_{a \in \mathcal{A}(s)} \pi(a \mid s) \sum_{s' \in \mathcal{S}} \sum_{r \in \mathcal{R}} p(s', r \mid s, a) \cdot \mathbb{E}_{\pi}[R_{t+1} + \gamma G_{t+1} \mid S_t = s, A_t = a, S_{t+1} = s', R_{t+1} = r]$$

Step D: linearity of expectation and constant evaluation

Apply linearity of expectation to split the sum into the immediate concrete reward \(r\) and future expected returns:

$$\begin{aligned}&\mathbb{E}_{\pi}[R_{t+1} + \gamma G_{t+1} \mid S_t = s, A_t = a, S_{t+1} = s', R_{t+1} = r]\\ &= r + \gamma \cdot \mathbb{E}_{\pi}[G_{t+1} \mid S_t = s, A_t = a, S_{t+1} = s', R_{t+1} = r]\end{aligned}$$

Step E: Markov simplification

By the Markov property, the distribution of \(G_{t+1}\) depends strictly upon the current state \(S_{t+1} = s'\). Historical variables \(S_t = s\), \(A_t = a\), and immediate reward \(R_{t+1} = r\) provide no additional information about future trajectories:

$$\mathbb{E}_{\pi}[G_{t+1} \mid S_t = s, A_t = a, S_{t+1} = s', R_{t+1} = r] = \mathbb{E}_{\pi}[G_{t+1} \mid S_{t+1} = s'] = V^{\pi}(s')$$

Step F: reassembly into the Bellman expectation equation

Substitute the simplified terms back into the overall expansion to yield the Bellman Expectation Equation for \(V^{\pi}(s)\):

$$V^{\pi}(s) = \sum_{a \in \mathcal{A}(s)} \pi(a \mid s) \sum_{s' \in \mathcal{S}} \sum_{r \in \mathcal{R}} p(s', r \mid s, a)\left[r + \gamma V^{\pi}(s')\right]$$
Drone check supplementThe equation says that the values of a policy must be consistent with each other. Check the claimed values \(V^{\pi^*} = \left[30.0000,\ 21.6667,\ 18.6667\right]^{T}\) (computed in Byte 8) for \(\pi^* = (\text{Del}, \text{Rech}, \text{Rech})\). With a deterministic policy and fixed rewards, the sums collapse to \(R(s,\pi(s)) + \gamma \sum_{s'} P(s' \mid s, \pi(s)) V(s')\):
High (Deliver): \(10 + 0.8(0.4 \cdot 30 + 0.6 \cdot 21.6667) = 10 + 0.8(25.0000) = 30.0000\) ✓
Low (Recharge): \(-1 + 0.8(0.8 \cdot 30 + 0.2 \cdot 21.6667) = -1 + 0.8(28.3333) = 21.6667\) ✓
Critical (Recharge): \(-2 + 0.8(0.5 \cdot 30 + 0.5 \cdot 21.6667) = -2 + 0.8(25.8333) = 18.6667\) ✓
Each value reproduces itself. A wrong guess, such as \(V = [0,0,0]\), would not: the right side would give \([10, -1, -2]\).

7Mutually recursive relationship between \(V^{\pi}\) and \(Q^{\pi}\)

The state-value function \(V^{\pi}\) and action-value function \(Q^{\pi}\) depend directly on one another.

Expressing \(V^{\pi}(s)\) via \(Q^{\pi}(s,a)\)

The value of a state equals the expected action-value across all policy-weighted actions:

$$V^{\pi}(s) = \sum_{a \in \mathcal{A}(s)} \pi(a \mid s)\, Q^{\pi}(s,a)$$

Expressing \(Q^{\pi}(s,a)\) via \(V^{\pi}(s')\)

The value of taking an action in a state equals expected immediate reward plus the discounted value of the resulting next state:

$$Q^{\pi}(s,a) = \sum_{s' \in \mathcal{S}} \sum_{r \in \mathcal{R}} p(s', r \mid s, a)\left[r + \gamma V^{\pi}(s')\right]$$

Bellman expectation equation for \(Q^{\pi}(s,a)\)

Substituting the expression for \(V^{\pi}(s')\) into \(Q^{\pi}(s,a)\) yields the self-consistent recursive equation for action values:

$$Q^{\pi}(s,a) = \sum_{s' \in \mathcal{S}} \sum_{r \in \mathcal{R}} p(s', r \mid s, a)\left[r + \gamma \sum_{a' \in \mathcal{A}(s')} \pi(a' \mid s')\, Q^{\pi}(s', a')\right]$$
Drone check supplementFor the stochastic \(\pi_{\text{mix}}\) of Byte 3 (coin flip in Low), the values are \(V^{\pi_{\text{mix}}} = \left[29.9877,\ 21.6493,\ 18.6548\right]^{T}\) (computed with the method of Byte 8). In Low:
\(Q^{\pi_{\text{mix}}}(\text{Low}, \text{Del}) = 6 + 0.8(0.3 \cdot 21.6493 + 0.7 \cdot 18.6548) = 21.6425\)
\(Q^{\pi_{\text{mix}}}(\text{Low}, \text{Rech}) = -1 + 0.8(0.8 \cdot 29.9877 + 0.2 \cdot 21.6493) = 21.6560\)
\(V^{\pi_{\text{mix}}}(\text{Low}) = 0.5 \cdot 21.6425 + 0.5 \cdot 21.6560 = 21.6493\) ✓ — the state value is the policy-weighted average of the action values, and it sits between them.

B3Background: linear systems in matrix form supplement

Why it is needed. Byte 8 writes the \(N\) Bellman equations as one matrix equation and solves it.

A set of \(N\) linear equations in \(N\) unknowns can be written \(M x = b\), where row \(i\) of the matrix \(M\) holds the coefficients of equation \(i\), \(x\) is the column of unknowns and \(b\) the right-hand sides. The product \(Mx\) is the column whose entry \(i\) is the dot product \(\sum_j M_{ij} x_j\). If \(M\) is invertible, the unique solution is \(x = M^{-1} b\). The identity matrix \(I\) (ones on the diagonal, zeros elsewhere) satisfies \(Ix = x\).

Example. \(x_1 = 1 + 0.5 x_2\) and \(x_2 = 2 + 0.5 x_1\). Move unknowns left: \(\begin{bmatrix}1 & -0.5\\ -0.5 & 1\end{bmatrix}\begin{bmatrix}x_1\\x_2\end{bmatrix} = \begin{bmatrix}1\\2\end{bmatrix}\), with solution \(x_1 = 8/3,\ x_2 = 10/3\). Check: \(1 + 0.5 \cdot 10/3 = 8/3\) ✓.

Cost. Solving a dense \(N\times N\) system by Gaussian elimination takes on the order of \(N^3\) operations, written \(O(N^3)\).

8Vector–matrix formulation of policy evaluation

For finite MDPs with state space size \(|\mathcal{S}| = N\), we can express the Bellman Expectation Equation system using linear algebra.

Matrix equation form

Define:

  • \(v^{\pi} \in \mathbb{R}^{N}\): state value vector, where \(v^{\pi}[i] = V^{\pi}(s_i)\).
  • \(r^{\pi} \in \mathbb{R}^{N}\): expected immediate reward vector under policy \(\pi\), where \(r^{\pi}[i] = \sum_a \pi(a \mid s_i) \sum_{s', r} p(s', r \mid s_i, a)\, r\).
  • \(P^{\pi} \in \mathbb{R}^{N \times N}\): policy state-transition probability matrix, where \(P^{\pi}[i,j] = \sum_a \pi(a \mid s_i) \sum_r p(s_j, r \mid s_i, a)\).

notation unified The original notes wrote \(v_\pi, r_\pi, P_\pi\) here; Lecture 2 uses \(v^{\pi}, r^{\pi}, P^{\pi}\). Both lectures now use the superscript form.

The system of equations simplifies to:

$$v^{\pi} = r^{\pi} + \gamma P^{\pi} v^{\pi}$$

Analytical solution

Rearranging terms using the identity matrix \(I \in \mathbb{R}^{N \times N}\):

$$(I - \gamma P^{\pi})\, v^{\pi} = r^{\pi} \qquad\Longrightarrow\qquad v^{\pi} = (I - \gamma P^{\pi})^{-1} r^{\pi}$$

Computational limits: matrix inversion incurs a computational complexity of \(O(|\mathcal{S}|^3)\). Exact inversion becomes intractable for large state spaces (e.g., \(|\mathcal{S}| > 10^4\)). Consequently, practical implementations resort to iterative policy evaluation methods (dynamic programming, temporal-difference learning, or Monte Carlo sampling).

Drone check supplementFor \(\pi^* = (\text{Del}, \text{Rech}, \text{Rech})\), pick from each state the row of the chosen action: $$r^{\pi^*} = \begin{bmatrix}10\\-1\\-2\end{bmatrix},\quad P^{\pi^*} = \begin{bmatrix}0.4 & 0.6 & 0.0\\ 0.8 & 0.2 & 0.0\\ 0.5 & 0.5 & 0.0\end{bmatrix},\quad I - 0.8P^{\pi^*} = \begin{bmatrix}0.68 & -0.48 & 0.00\\ -0.64 & 0.84 & 0.00\\ -0.40 & -0.40 & 1.00\end{bmatrix}$$ The first two equations involve only High and Low: \(0.68x_0 - 0.48x_1 = 10\) and \(-0.64x_0 + 0.84x_1 = -1\), giving \(x_0 = 30,\ x_1 = 65/3 \approx 21.6667\). 9Moving from evaluation to control (Bellman optimality)

Partial ordering of policies

A policy \(\pi\) is defined to be better than or equal to a policy \(\pi'\) (\(\pi \ge \pi'\)) if and only if its expected return is greater than or equal to that of \(\pi'\) for all states:

$$\pi \ge \pi' \iff V^{\pi}(s) \ge V^{\pi'}(s) \quad \forall\, s \in \mathcal{S}$$

For a finite MDP, there is always at least one policy that is equal to or better than all other policies. This is an optimal policy, denoted \(\pi^{*}\).

Why "partial" supplementTwo policies can be incomparable. For the drone, \(\pi_a = (\text{Del}, \text{Del}, \text{Del})\) has \(V = \left[7.2755,\ -10.5263,\ -25.0000\right]^{T}\) and \(\pi_b = (\text{Rech}, \text{Del}, \text{Rech})\) has \(V = \left[0.0000,\ 9.1045,\ 1.6418\right]^{T}\): \(\pi_a\) is better in High, \(\pi_b\) is better in Low and Critical, so neither \(\pi_a \ge \pi_b\) nor \(\pi_b \ge \pi_a\). Yet among all \(2^3 = 8\) deterministic policies, \((\text{Del}, \text{Rech}, \text{Rech})\) is \(\ge\) every one of them in every state (checked by evaluating all eight) — it is \(\pi^*\).

Optimal value functions

The optimal state-value function \(V^{*}(s)\) is the maximum state-value obtainable under any policy:

$$V^{*}(s) \doteq \max_{\pi} V^{\pi}(s) \quad \forall\, s \in \mathcal{S}$$

The optimal action-value function \(Q^{*}(s,a)\) is the maximum action-value obtainable under any policy:

$$Q^{*}(s,a) \doteq \max_{\pi} Q^{\pi}(s,a) \quad \forall\, s \in \mathcal{S},\ a \in \mathcal{A}(s)$$

This leads to the identity connecting \(V^{*}\) and \(Q^{*}\):

$$V^{*}(s) = \max_{a \in \mathcal{A}(s)} Q^{*}(s,a)$$

Bellman optimality equation for \(V^{*}(s)\)

Because the optimal policy chooses the action that maximizes expected long-term return, the optimal state value must equal the maximum expected value across candidate actions:

$$V^{*}(s) = \max_{a \in \mathcal{A}(s)} \sum_{s' \in \mathcal{S}} \sum_{r \in \mathcal{R}} p(s', r \mid s, a)\left[r + \gamma V^{*}(s')\right]$$

Bellman optimality equation for \(Q^{*}(s,a)\)

Similarly, the optimal action-value system satisfies:

$$Q^{*}(s,a) = \sum_{s' \in \mathcal{S}} \sum_{r \in \mathcal{R}} p(s', r \mid s, a)\left[r + \gamma \max_{a' \in \mathcal{A}(s')} Q^{*}(s', a')\right]$$

Linear vs. non-linear systems

  • Bellman expectation equations are linear systems of equations for a fixed policy \(\pi\). They can be solved analytically using matrix inversion or iteratively via linear operators.
  • Bellman optimality equations are non-linear systems of equations due to the presence of the non-linear \(\max\) operator. As a result, direct linear solvers cannot be used. We must use non-linear iterative algorithms such as value iteration, policy iteration, or Q-learning — the subject of Lecture 2.

·Consolidated mental model supplement

  1. The world (Bytes 0–2): a Markov state plus the dynamics \(p(s', r \mid s,a)\) describe everything the environment can do; summing out pieces gives \(P(s' \mid s,a)\) and \(R(s,a)\).
  2. The agent (Bytes 3–5): a policy \(\pi\) chooses actions; the return \(G_t\) scores a run; \(V^{\pi}\) and \(Q^{\pi}\) are the average scores.
  3. Consistency (Bytes 6–8): because \(G_t = R_{t+1} + \gamma G_{t+1}\) and the state is Markov, every value equals "reward now + \(\gamma\) × value next", averaged. For a fixed \(\pi\) this is a linear system you can solve.
  4. Optimality (Byte 9): replace "average over \(\pi\)'s actions" by "max over actions" and you get the equations for the best possible values. The max makes them non-linear — which is why Lecture 2 needs iterative algorithms.
