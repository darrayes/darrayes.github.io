5-Step Algebraic Derivation Recap (Scalar Bellman Equation → Matrix Equation)
  1. Index states s0, …, sN−1: write Vπ(si) = ∑a π(a | si) [ R(si, a) + γ ∑j P(sj | si, a) Vπ(sj) ].
  2. Distribute π(a | si) across the bracket to split immediate reward from discounted next-state value.
  3. Swap the two finite sums ∑a and ∑j in the second term, factoring Vπ(sj) outside the inner action sum.
  4. Collapse action sums into policy-averaged tables: rπ[i] = ∑a π(a|si) R(si,a) and Pπ[i,j] = ∑a π(a|si) P(sj|si,a).
  5. Stack all N scalar equations vertically to obtain vπ = rπ + γ Pπ vπ, then turn into the sweep update vk+1 = rπ + γ Pπ vk.
